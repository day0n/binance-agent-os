# 赛道一演示清单

先通过 VALIDATION.md 的真实接口项再录制；不要把未接通界面包装成成功运行。

## 三分钟演示脚本

1. **20 秒：问题与边界**。展示中文工作台，说明研究、现货体检、回测；不执行实盘交易。
2. **30 秒：连接**。展示官方支持的 Codex OAuth 与真实只读调用验收记录，并明确自建网站
   OAuth 尚未开放。不要展示登录密码、验证码、令牌或用户不愿公开的余额。
3. **50 秒：市场研究**。只有生产 Web OAuth 获得官方支持并完成端到端验收后，才演示
   BTCUSDT 日线研究、专业节点、多空分歧与风险复核。
   打开一条证据，核对数据时点、来源、哈希及计算数字。
4. **40 秒：策略实验室**。用同一真实历史数据运行均线交叉，显示费用、滑点、基准与回撤。
   解释前一根收盘信号、下一根开盘成交。
5. **20 秒：账户体检**。使用获准展示的账户，强调 spot-only、未定价资产与集中度限制。
   不公开余额时说明隐私原因，不能换成伪造账户。
6. **20 秒：可靠性**。刷新页面、查看历史、SSE 补齐事件；演示明确的缺配置/取消状态。

## 提交材料

- 公开 GitHub 仓库、可访问站点、演示视频链接。
- 架构说明、只读安全边界、真实数据来源和验收记录。
- 明确依赖 Binance 授权，以及未覆盖的新闻、链上和衍生品范围。
- 项目独立性、开源许可及研究免责声明。
