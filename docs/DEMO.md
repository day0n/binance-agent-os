# 赛道一演示清单

先对照 [VALIDATION.md](VALIDATION.md)。不要把未接通的执行器或关闭的写开关包装成实盘成功。

## 三分钟演示脚本

1. **20 秒：产品**。打开 Chat：会话栏、输入框、研究画布。说明这是独立研究工具，不是币安官方产品。
2. **20 秒：账号**。注册或登录；说明没有邮箱验证码，也没有忘记密码。
3. **40 秒：研究**。用公共 REST 做 BTCUSDT 研究或回测。打开证据，核时点与来源。
   若 Gemini / 数据不可用，展示明确失败，不要切到演示行情。
4. **30 秒：边界**。说明官方 MCP 已在 Codex 验证，但网站 OAuth 仍不受支持；
   网站用 REST + API Key 信封，不会显示虚假的 MCP 已连接。
5. **30 秒：动作卡**。若已连接 Testnet Key 且用户同意，展示精确预览。
   强调聊天输入“确认”不会下单，必须重新输入当前账号密码。
6. **20 秒：额度**。单笔 5 USDT、每日 20 USDT；生产写入默认关闭。

## 不要演示

- 未打开开关时的“已成交”。
- 提现、外部转账、合约或任意 URL。
- OpenCreator 项目、真实 API Secret、密码或完整请求体。
- 用户不在场时的生产下单。

## 提交材料

- 公开 GitHub 仓库、可访问站点、演示视频链接。
- 架构、安全边界、真实数据来源和分层验收记录。
- 明确网站 OAuth 限制与 Executor / canary 未完成项。
